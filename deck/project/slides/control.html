Matched stores, randomly assigned, all on the same calendar

1 · MATCH

Group stores in threes by store type and baseline sales per sq ft

2 · RANDOMISE

Within each triplet, assign one store to each group

3 · COMPARE

Effect = change in test stores − change in control stores

Groups average $22.3–$23.7 of weekly sales per sq ft. A simple before-vs-after can’t work: 2023’s +4% “after” effect may be partly the spring-to-summer ramp.

Random assignment within triplets (seed 2027); swap within a triplet if two stores share a metro

How do we know the strategy works? A proper control group. We group the 25 stores into threes that look alike: same store type, similar sales per square foot, which we now know is the biggest driver of lift. Within each three, we randomly assign one store to Community Days, one to Event plus ReGear, and one to no promotion. All stores run on the same weeks, so weather, holidays and season hit everyone equally. We measure each store against its own baseline, and the effect is the test stores’ change minus the control stores’ change. The groups come out well balanced. This fixes the biggest weakness of the 2023 data, where we had no untreated stores to compare against.
